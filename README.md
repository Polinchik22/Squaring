# Quadratic Equation Solver

A C++17 command-line program for solving quadratic equations. It includes built-in checks for the solver and plots the resulting function with [raylib](https://www.raylib.com/).

## Build and run

The project uses a Makefile:

```bash
make
./programm
```

The build uses GNU Make, a C++17 compiler, raylib, and SDL2.

## Project layout

- `src/` — program implementation
- `header/` — declarations and shared definitions
- `Makefile` — build rules and compiler checks
- `tests.txt` — test data
